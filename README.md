**A small, transparent backtesting lab for crypto spot strategies on OHLCV candles.**

Most backtesting frameworks are either a few lines of vectorized pandas that quietly peek
into the future, or large engines whose fill logic is hard to audit. candlelab sits in
between: a tiny, well-tested core whose timing and cost model you can read in five minutes,
plus a CLI that goes from *public market data* to *trade list* in two commands.

It started as a way to choose moving-average parameters for a TradingView → exchange
signal bot without trusting a black box.

```text
$ candlelab fetch BTCUSDT --interval 1d --start 2020-01-01 -o data/btcusdt_1d.csv
$ candlelab backtest data/btcusdt_1d.csv -p fast=20 -p slow=50 --fee 0.001 --slippage 0.0005
```

## Features

- **No look-ahead by construction** - a signal formed at bar *t*'s close is filled at bar
  *t+1*'s open. The last bar's signal is never executed.
- **Explicit costs** - per-side fee rate and slippage, applied against you on every fill.
- **Public data, no keys** - downloads spot candles from Binance's public market-data host
  (`data-api.binance.vision`). candlelab never needs, reads or stores API keys.
- **Drops the still-forming candle** when fetching up to "now", so results don't change
  after the fact.
- **Strict input validation** - timestamps (ISO or epoch s/ms/µs/ns) are normalized to UTC;
  rows with broken OHLC relationships are rejected with the offending timestamp.
- **Pluggable strategies** - a strategy is a dataclass that returns a target position per
  bar; parameters are discovered automatically for the CLI.
- **Readable outputs** - summary table, trades CSV and equity-curve CSV.

## Install

Requires Python 3.10+. On Windows, use WSL2.

```bash
git clone https://github.com/Phoen1x1996/candlelab.git
cd candlelab
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
```

## Quick start

Try it offline on the synthetic sample:

```bash
candlelab strategies
candlelab backtest examples/synthetic_daily.csv -p fast=10 -p slow=30 -p kind=ema \
    --trades-out reports/trades.csv --equity-out reports/equity.csv
```

Then on real data:

```bash
candlelab fetch ETHUSDT --interval 4h --start 2023-01-01 -o data/ethusdt_4h.csv
candlelab backtest data/ethusdt_4h.csv -p fast=12 -p slow=48 --start 2024-01-01
```

`--start/--end` on `backtest` restrict the *trading* window; indicators are still computed
on the full file, so the first bars of the window are not wasted on warm-up.

### Python API

```python
from candlelab import BacktestConfig, get_strategy, load_csv, run_backtest, summarize

candles = load_csv("data/btcusdt_1d.csv")
strategy = get_strategy("ma_cross", fast=20, slow=50, kind="ema")
result = run_backtest(candles, strategy.target_position(candles), BacktestConfig(fee_rate=0.001))
print(summarize(result, candles))
```

## How the simulation works

| Step | Rule |
| --- | --- |
| Signal | `target[t]` ∈ {0, 1} using information up to the **close** of bar *t* |
| Execution | changes are filled at the **open** of bar *t+1* |
| Sizing | long-only, all-in: entries spend all cash, exits sell everything |
| Slippage | buys fill at `open × (1 + slippage)`, sells at `open × (1 − slippage)` |
| Fees | `fee_rate` × traded notional, charged in the quote currency on each side |
| Valuation | equity is marked to market at each close; an open trade at the end is reported as open |

Metrics: total return, CAGR (365.25-day years), max drawdown, annualized Sharpe (zero
risk-free rate, bars-per-year inferred from the data), exposure, win rate, profit factor,
average trade return, fees, and buy-and-hold (close-to-close, no fees) for comparison.

## CSV format

```text
time,open,high,low,close,volume
2024-01-01T00:00:00Z,100.0,105.0,98.5,104.2,1250.0
```

`time` may also be called `timestamp`, `open_time`, `datetime` or `date`; column names are
case-insensitive. Times are candle **open** times.

## Project layout

```text
src/candlelab/
  data.py          normalization, CSV I/O, Binance public klines fetcher
  indicators.py    SMA / EMA
  strategies/      Strategy base class, registry, ma_cross
  engine.py        next-bar-open execution with fees and slippage
  metrics.py       summary statistics
  report.py        text summary and CSV writers
  cli.py           `candlelab` command
tests/             pytest suite (runs offline)
```
